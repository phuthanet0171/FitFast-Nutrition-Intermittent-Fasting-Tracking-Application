FitFast คือแอปพลิเคชันสำหรับจัดการโภชนาการและติดตามการทำ Intermittent Fasting (IF) เหมาะสำหรับผู้ที่ต้องการควบคุมน้ำหนัก วางแผนการรับประทานอาหาร และติดตามพฤติกรรมสุขภาพของตนเองอย่างเป็นระบบ
แอปพัฒนาด้วย Flutter และ Dart โดยให้ความสำคัญกับการใช้งานที่เข้าใจง่าย รองรับการบันทึกอาหารไทย และแสดงข้อมูลที่ช่วยให้ผู้ใช้ติดตามเป้าหมายสุขภาพของตนเองได้สะดวกมากขึ้น
วัตถุประสงค์ของโครงการ
- ช่วยให้ผู้ใช้ทำ Intermittent Fasting ได้อย่างเป็นระบบ
- ช่วยคำนวณพลังงานและสารอาหารที่เหมาะสมในแต่ละวัน
- ช่วยบันทึกและติดตามอาหารที่รับประทาน
- สนับสนุนการควบคุมน้ำหนักและการปรับพฤติกรรมการกิน
- แสดงความก้าวหน้าด้านสุขภาพในรูปแบบที่เข้าใจง่าย
ฟีเจอร์หลัก
1. ระบบสมาชิกและข้อมูลส่วนตัว
- สมัครสมาชิกและเข้าสู่ระบบ
- บันทึกอายุ เพศ ส่วนสูง และน้ำหนักปัจจุบัน
- กำหนดน้ำหนักเป้าหมาย
- เลือกระดับกิจกรรมในชีวิตประจำวัน
- แก้ไขข้อมูลส่วนตัวภายหลังได้
2. การคำนวณเป้าหมายสุขภาพ
ระบบสามารถคำนวณข้อมูลเบื้องต้นจากข้อมูลของผู้ใช้ ได้แก่
- ดัชนีมวลกาย (BMI)
- อัตราการเผาผลาญพลังงานพื้นฐาน (BMR)
- พลังงานที่ร่างกายใช้ต่อวัน (TDEE)
- เป้าหมายแคลอรีต่อวัน
- ปริมาณโปรตีน คาร์โบไฮเดรต และไขมันที่แนะนำ
- เป้าหมายน้ำตาลและโซเดียม
3. แผน Intermittent Fasting
ผู้ใช้สามารถเลือกแผนการทำ IF ที่เหมาะกับตนเอง ได้แก่
- 16/8 — อดอาหาร 16 ชั่วโมง และรับประทานอาหารภายใน 8 ชั่วโมง
- 18/6 — อดอาหาร 18 ชั่วโมง และรับประทานอาหารภายใน 6 ชั่วโมง
- 20/4 — อดอาหาร 20 ชั่วโมง และรับประทานอาหารภายใน 4 ชั่วโมง
ระบบมีตัวจับเวลาเพื่อแสดงระยะเวลาการอดอาหารและช่วงเวลาที่สามารถรับประทานอาหารได้
4. การบันทึกอาหารและสารอาหาร
- ค้นหาและเลือกเมนูอาหาร
- รองรับอาหารไทยและอาหารทั่วไป
- บันทึกอาหารแยกตามมื้อ
- คำนวณแคลอรีและสารอาหารที่ได้รับ
- แสดงปริมาณโปรตีน คาร์โบไฮเดรต ไขมัน น้ำตาล และโซเดียม
- เปรียบเทียบสารอาหารที่ได้รับกับเป้าหมายประจำวัน
5. การติดตามความก้าวหน้า
- บันทึกน้ำหนักในแต่ละวัน
- แสดงประวัติน้ำหนัก
- แสดงกราฟการเปลี่ยนแปลงของน้ำหนัก
- ติดตามความสำเร็จในการทำ IF
- สรุปข้อมูลแคลอรีและสารอาหารประจำวัน
6. การแจ้งเตือน
- แจ้งเตือนเมื่อเริ่มและสิ้นสุดช่วงอดอาหาร
- แจ้งเตือนเวลารับประทานอาหาร
- แจ้งเตือนการบันทึกน้ำหนักและมื้ออาหา
เทคโนโลยีที่ใช้
- Flutter — พัฒนาแอปพลิเคชัน
- Dart — ภาษาหลักในการพัฒนา
- Android Studio — Android SDK และ Emulator
- Visual Studio Code — เขียนและจัดการโค้ด
- Git และ GitHub — ควบคุมเวอร์ชันและจัดเก็บโครงการ
- Figma — ออกแบบ UX/UI
